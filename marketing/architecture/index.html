โครงสร้างระบบ BOXBLACK

แอป Mac ที่อ่านโปรเจค CapCut บนเครื่อง ให้ Claude ช่วยคิด แล้วเขียน timeline กลับลงโปรเจคเดิม วาดจากโค้ดเวอร์ชัน 0.8.3

1 · ส่วนประกอบ และใครคุยกับใคร

งานหนักทั้งหมดทำบนเครื่อง Mac ของผู้ใช้ สิ่งที่ออกไปนอกเครื่องมีแค่ภาพกับคำพูดที่ส่งให้ Claude และเสียงที่ส่งให้ ElevenLabs เมื่อเลือกใช้

2 · ข้อมูลไหลผ่านขั้นตอนอย่างไร

จากวิดีโอดิบในโปรเจคจนเป็น timeline ที่แต่งเสร็จ ช่องสีม่วงคือขั้นที่เรียก Claude ส่วนช่องอื่นคำนวณบนเครื่องทั้งหมด

เลือกทาง Claude ได้ 2 แบบใช้ Anthropic API key ของผู้ใช้เอง หรือใช้ Claude Code ที่ล็อกอินบัญชี Claude ไว้บนเครื่อง main process เลือกจากหน้าตั้งค่าในทุกครั้งที่เรียก
ไม่ต้อง export วิดีโอแอปอ่านไฟล์วิดีโอต้นฉบับจากคลังสื่อของโปรเจคโดยตรง และเขียนผลเป็น JSON ของ CapCut จึงไม่มีการเรนเดอร์วิดีโอทั้งคลิป
License ยังไม่เปิดใช้โค้ดมี server และระบบผูกเครื่องพร้อมแล้ว (token ลายเซ็น Ed25519 ใช้ออฟไลน์ได้ 3 วัน) แต่ตอนนี้ยังไม่ได้บังคับใช้
