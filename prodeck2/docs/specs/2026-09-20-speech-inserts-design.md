# M12 · สื่อแทรกตามคำพูด (speech inserts) — design

วันที่ 2026-09-20 · ต่อจาก M10.4 (สื่อแทรก) และ M11 (หน้าตาแอปใหม่)

## 1. ปัญหา

M10.4 ให้ Claude แทรกรูปจากกรุสื่อได้ แต่ "จุดที่แทรกได้" คือจุดเดียวกับเสียงประกอบ: บรรทัดข้อความเด่น
ต้นช่วง ท้ายช่วง รอยตัด — จุดเหล่านั้นถูกเลือกด้วยเกณฑ์อื่น (คำกระแทกตา จังหวะ) ไม่ใช่ "ตรงที่พูดถึงของ"
ผลคือ

- prompt สั่งว่า "แทรกเฉพาะตอนที่คนพูดกำลังพูดถึงสิ่งนั้นจริงๆ" แต่ให้เลือกได้แค่จุดที่มีอยู่ Claude จึงตอบว่างบ่อยทั้งที่มีประโยคที่พูดถึงของอยู่ชัดๆ
- ปิดข้อความเด่น (หรือยังไม่ได้เลือก) = ไม่มีจุด = ไม่มีสื่อแทรก และปุ่ม "จัดลูกเล่น" ก็กดไม่ได้ทั้งเมนู
- ผู้ใช้เลือกรูปเองได้เฉพาะที่จุดเหล่านั้น เลือกที่ประโยคไม่ได้

ผู้ใช้ถามว่าตอนวางโครงเรื่องมีแนวคิดเรื่องภาพแทรกไหม (2026-09-20) และเลือกแก้ที่ชั้นแต่งตามข้อเสนอ:
ให้สื่อแทรกเกาะคำพูด ไม่แตะโครงเรื่อง ไม่ขุด b-roll จากคลิปพูด ไม่หารูปเพิ่ม

## 2. สิ่งที่ผู้ใช้เลือก

- เลือกรูปด้วยมือ **ในแท็บคำพูด ที่บรรทัดนั้นเลย** (ไม่ใช่รายการประโยคในแท็บลูกเล่น)
- **"จัดลูกเล่น" กดได้เมื่อมีอะไรให้จัด** ไม่ต้องมีข้อความเด่นก่อน

## 3. แนวคิด

สื่อแทรก 1 อัน = "ที่ประโยคนี้ ตรงคำว่า …" · เก็บเป็น anchor ชนิดใหม่

```ts
{ kind: "speech"; videoId: string; sourceUs: number }
```

`sourceUs` คือเวลาในไฟล์ต้นทางที่รูปเริ่มขึ้น: ต้นคำที่ Claude (หรือผู้ใช้) เลือก ไม่มีคำ = ต้นประโยค ·
anchor ชนิดเดิมสามชนิด (highlight / cut / beat) ยังอยู่ในชนิด `CueAnchor` เพราะเสียงประกอบใช้
และสื่อแทรกที่เก็บไว้บนจุดเหล่านั้นจาก M10.4 ยังเล่นได้ แต่ Claude ไม่ถูกเสนอให้แทรกรูปที่จุดเหล่านั้นอีก

เมื่อตัดหยาบเปลี่ยน anchor ยังอยู่ (เวลาในไฟล์ต้นทางไม่เปลี่ยน) · ถ้าประโยคนั้นถูกตัดออกจากตัดหยาบ
ชิ้นที่ครอบ `sourceUs` ไม่มี รูปก็ไม่เล่นและถูกนับเป็นของที่หายไป — เหมือนสื่อแทรกบนจุดที่หายไปใน M10.4

## 4. Claude เห็นอะไร ตอบอะไร

เพิ่มส่วน "ประโยคที่แทรกรูปได้" ในคำขอจัดลูกเล่น: ทุกประโยคที่ตัดหยาบเล่นจริง (แถว `used` และ `kept`
ที่เป็นคำพูด) เรียงตามเวลาบน timeline

```
ประโยคที่แทรกรูปได้
[1] 0:00.0 “ขึ้นไปในอวกาศ ในสาม สอง”
[2] 0:04.4 “สาม สอง หนึ่ง”
```

คำตอบ `inserts: [{ at: 1, picture: 2, word: "อวกาศ" }]` — `at` ชี้ประโยคในรายการนี้ (ไม่ใช่จุดเสียง)
`word` คือคำในประโยคที่รูปควรขึ้น ว่างได้ · โปรแกรมหาคำในรายการคำที่มีเวลาของประโยคนั้น
(`findWord` แบบเดียวกับคำเน้นสี แต่เทียบกับข้อความของแต่ละคำ) ได้ต้นคำเป็น `sourceUs` · ไม่พบ = ต้นประโยค
และไม่นับเป็นของตก (แค่ตำแหน่งหยาบลง) · `at` ที่ไม่มี หรือรูปที่ไม่มี หรือประโยค/รูปที่ใช้ซ้ำ = ตกและนับ

กฎใน prompt: แทรกเฉพาะตอนพูดถึงสิ่งนั้นจริงๆ · รูปหนึ่งใช้ครั้งเดียว · ประโยคหนึ่งรูปเดียว · ไม่มีก็ตอบว่าง ·
ระบุคำถ้าชี้ได้ว่าพูดถึงของตรงคำไหน · `FLAIR_PROMPT_VERSION` = `flair-2026-09-20-speech-inserts`

`planFlair` เลิก return ทันทีเมื่อไม่มีชุดข้อความเด่น: มันเรียก Claude เมื่อมี**อะไรสักอย่าง**ให้จัด
(ชุดข้อความ / จุดเสียง+เสียง / ชิ้นซูม / ประโยค+รูป) และ prompt บอกว่า "ไม่มีชุดข้อความเด่น ตอบ groups เป็นรายการว่าง"

## 5. ฝั่ง main

- `spoken.ts` (ใหม่): `spokenSentences(plan, wordsOf, beatNames, at)` — loop เดียวกับที่ `highlights.pick`
  ใช้สร้าง `HighlightSentence[]` แยกออกมาใช้ร่วม ให้ทั้ง pick ข้อความเด่นและรายการประโยคของสื่อแทรก
  ผลลัพธ์แต่ละประโยค: `videoId, beatId, beatName, from, to, text, timelineUs, words[]` (คำพร้อมเวลาต้นทาง)
- `insert-media.ts`: `insertsInForce` เปลี่ยนจากรับ `slots` เป็นรับ `place(anchor)` ที่คืน
  `{ atUs, what, beatId } | null` · ตัวแปลง `placeOf({ slots, sentences, plan, at })`:
  anchor highlight/cut/beat → หาใน slots (เหมือนเดิม) · anchor speech → หาชิ้นของวิดีโอนั้นที่ครอบ `sourceUs`
  แล้ว `atUs = at(cutIndex, sourceUs)` · `what` = `ที่ “ประโยค” ตรงคำว่า “คำ”` (คำที่ต้นเวลาตรง sourceUs)
  หรือ `ที่ “ประโยค”` · `beatId` ของชิ้นนั้น
- `flair.ts plan()`: สร้างประโยคเมื่อ `flair.insert` และมีรูป ส่งเป็น `sentences` ให้ `planFlair` ·
  เก็บ inserts ที่ได้ (anchor speech) รวมกับที่ผู้ใช้ตั้งเองเหมือนเดิม
- `highlights.ts insertView` และ `timeline.ts insertCutaways`: ใช้ `placeOf` แทน slots
- `highlight-api.ts checkedAnchor`: รับ `{ kind: "speech", videoId: string, sourceUs: integer ≥ 0 }`
- `setInsert` เดิมพอ: ลบด้วย anchorKey ตรงกัน · UI ส่ง anchor ของสื่อแทรกที่มีอยู่เมื่อเปลี่ยน/เอาออก
  และส่ง `{ kind: "speech", videoId, sourceUs: row.startUs }` เมื่อตั้งใหม่ (`row.startUs` = ต้นคำแรกของแถว)

## 6. หน้าจอ

- **แท็บคำพูด** (`SpeechTab`): แถว `used`/`kept` ที่มีข้อความ เมื่อสื่อแทรกเปิดและมีรูปในกรุสื่อ
  มีปุ่ม `รูป` ต่อจาก ▶ เน้น ตัด · กดแล้วเปิด `Popover` รายการรูป (สิ่งที่ AI เห็น / ชื่อไฟล์, "(คลิป)")
  และ "ไม่แทรก" · แถวที่มีสื่อแทรกอยู่ (anchor speech ของวิดีโอนั้นที่ `sourceUs` อยู่ใน [startUs, endUs))
  ขึ้นป้าย `mark insert` 🖼 ชื่อรูป และ "คุณตั้งเอง" เมื่อ edited
- **แท็บลูกเล่น** (`FlairTab`): ส่วน "จุด" เหลือแค่เลือกเสียง · เพิ่มส่วน "สื่อแทรกในบีต": เวลา · รูป ·
  `what` · ปุ่ม `เอาออก` · เมื่อสื่อแทรกเปิดแต่ไม่มีเลย บอกว่า "เลือกจากปุ่ม รูป ในแท็บคำพูด"
- **เมนู AI**: "จัดลูกเล่น" ปิดเมื่อลูกเล่นปิด หรือ preview ยังไม่มา หรือ **ไม่มีอะไรให้จัด**
  (ไม่มีชุดข้อความ และไม่มีรูป และไม่มีชิ้นซูม และไม่มี(จุด+เสียง)) · ข้อความ `edit.ai.nothing`
- ป้ายนับ 🖼 ในแถบข้าง และ `byBeat` ไม่เปลี่ยน (inserts มี `beatId` อยู่แล้ว)

## 7. ไม่อยู่ในขอบเขต

- Claude แทรกรูปที่จุดเสียง (ของเก่าที่เก็บไว้ยังเล่น)
- ดึง b-roll จากในคลิปพูดมาเป็นสื่อแทรก · หา/สร้างรูปเพิ่ม
- โครงเรื่อง prompt กติกา enforce (2 วิ/3 วิ/ห่าง 3 วิ/โควตา) และรูปแบบ overlay track ใน draft
