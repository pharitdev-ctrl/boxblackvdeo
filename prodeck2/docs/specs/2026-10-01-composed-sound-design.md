# เสียงเอฟเฟกต์ที่ Claude แต่งเอง (0.6.0)

- สถานะ: ทำเสร็จแล้วใน 0.6.0 (2026-10-01) ผู้ใช้เลือกแนวทาง A และอนุมัติสเปก 2026-10-01 · ผู้ใช้ฟังใน CapCut แล้วว่าเสียงเข้ากับวิดีโอ export ไม่ขึ้น Pro · ผู้ใช้เลือกให้ Claude เลือกสไตล์เสียงเองทุกคลิป (ไม่มีช่องให้ผู้ใช้กำหนดสไตล์)
- ที่มา: ผู้ใช้อยากได้ "เสียงดนตรีเอฟเฟกต์" ที่เข้ากับวิดีโอจริงๆ เพราะเสียงสำเร็จรูปของ CapCut บางเสียงไม่เข้ากับคลิป และต้องไม่มีค่าใช้จ่าย
- แทนที่: งานที่ 4 แบบเดิมที่ Claude เลือกเสียง CapCut ลงช่องเสียงตายตัว (`docs/specs/2026-09-27-post-production-design.md` §5.6)
- ผลทดลอง: `docs/plans/2026-10-01-sound-spike/`

## 2. สิ่งที่พิสูจน์แล้ว (ทดลอง 2026-10-01)

- Claude ตั้งชุดเสียงของคลิปในการเรียกเดียว (9 วินาที) แล้วแต่ง 4 เสียงของ 0917 พร้อมกัน (24–42 วินาทีต่อเสียง) เรนเดอร์ผ่านครั้งแรกทั้ง 4 ไม่ต้องซ่อม
- เสียงลงตรงคำที่ตั้งใจถึงหลักร้อยของวินาที (นับถอยหลัง 0 · 1.26 · 2.22 = สาม สอง หนึ่ง) และตามจังหวะภาพของกราฟิกเมื่อได้โค้ดของกราฟิกไป
- เสียงมีชั้นจริง (ลมฟิ้วจาก noise เสียงประสาน เสียงไถล หางเสียงก้อง) ไม่ใช่เสียงทดสอบเปล่า · ทั้งคลิปใช้ท่อนโน้ตประจำคลิปเดียวกัน
- ความดังดิบต่างกันมาก (−31.6 ถึง −19.6 LUFS) แอปต้องปรับเอง
- ยังไม่ได้พิสูจน์: CapCut รับไฟล์ WAV ในเครื่องเป็นเสียงในดราฟต์ได้ไหม และต้องเขียนอย่างไร (งานแรกของแผน §11) · เรนเดอร์ในหน้าต่างซ่อนของแอปเอง (ทดลองใช้ Chrome ของชุดเรนเดอร์)

## 3. ภาพรวมการทำงาน

งาน "เสียง" (งานที่ 4) ยังเป็นงานสุดท้ายของรอบวางแผน เพราะต้องรู้เวลาของทุกอย่างที่งานอื่นวาง

1. **วางแผน (หนึ่งครั้งต่อคลิป):** Claude ได้คำพูดพร้อมเวลาบนคลิปที่ตัด บีต จุดเน้นพร้อมความสำคัญ ระดับที่เลือก ข้อความเด่น (บรรทัดและเวลา) กราฟิกที่เขียนแล้ว (ไอเดียและโค้ด) ซูมและจังหวะ punch สื่อแทรก แล้วตอบ:
   - **ชุดเสียงของคลิป:** คีย์ ความรู้สึกของจังหวะ เครื่องเสียง (เป็นเสียงสังเคราะห์ที่เขียนด้วย Web Audio ได้) นิสัยของเสียง ท่อนโน้ตประจำคลิป และสิ่งที่ห้าม · ไม่เกิน 8 บรรทัด
   - **รายการเสียง:** แต่ละเสียงเริ่มที่คำไหน (หรือที่กราฟิกไหน) ยาวเท่าไหร่ หน้าที่ (ภาษาไทยหนึ่งประโยค ใช้เป็นโจทย์และเป็นคำอธิบายในแถว) ผูกกับจุดเน้นไหน ผูกกับกราฟิกไหน ระดับต่ำสุดที่เล่น (เบา กลาง จัดเต็ม) และความดัง (เบา กลาง ดัง)
   - ระดับจุดเน้นเป็นแนวทาง: เบา = เฉพาะจังหวะสำคัญจริง · จัดเต็ม = แน่นทั้งคลิป · ไม่มีจำนวนตายตัว (กติกา M25 ไม่ตั้งเพดานให้ Claude)
2. **แต่ง (หนึ่งครั้งต่อเสียง ทำพร้อมกัน 3 เสียง):** Claude ได้กติกา (§5) ชุดเสียงของคลิป หน้าที่ ความยาว คำที่พูดพร้อมเวลานับจากเริ่มเสียง และโค้ดของกราฟิกที่ผูก (ถ้ามี) แล้วตอบเป็นฟังก์ชันเดียว
3. **ตรวจ:** ตัวตรวจโค้ด (§6.1) แล้วเรนเดอร์และตรวจเสียง (§6.2) · ไม่ผ่านซ่อมได้หนึ่งรอบ (ใช้ `repairBrief` ของ 0.5.0) · ยังไม่ผ่านเก็บเหตุผลและขึ้นว่าล้มเหลว
4. **ปรับความดัง:** แอปวัดความดังด้วย ffmpeg (`ebur128`) แล้วปรับเป็น −30 / −26 / −22 LUFS ตามความดังที่ Claude ตั้ง (ตัวเลขตั้งต้น ปรับได้หลังลองจริง)
5. **ใช้:** เสียงที่ผ่านเขียนลงดราฟต์เป็นไฟล์ WAV บนแทร็กเสียง (§9)

ระหว่างแต่ง แถบแผนบอก "กำลังแต่งเสียง 2 จาก 11" · กด "หยุด" หยุดได้ทุกช่วง เสียงที่แต่งเสร็จแล้วยังอยู่ เสียงที่ยังตรวจไม่จบไม่ถูกเก็บ

**หนึ่งที่ หลายเสียงได้:** เสียงซ้อนกันได้ (คนละแทร็ก) เสียงถูกระบุด้วยจุดเริ่ม (anchor) กับลำดับที่ Claude ให้ ถ้าสองเสียงเริ่มที่เดียวกันทุกประการ เก็บเสียงแรก

## 4. ข้อมูล

เสียงที่แต่งเก็บใน outline เป็นรายการใหม่ `flair.composed` แยกจาก `flair.cues` (เสียง CapCut) · ชุดเสียงของคลิปเก็บที่ `flair.palette`

`ComposedSound`:

| ช่อง | ความหมาย |
|---|---|
| `anchor` | จุดเริ่ม: คำพูด (`speech`) ที่เวลาใดก็ได้ในชิ้นที่เก็บ |
| `graphic` | anchor ของกราฟิกที่เสียงนี้ผูก (ถ้ามี) เสียงตามกราฟิกนั้น: ปิด ลบ ย้อน ทำใหม่ |
| `graphicHtml` | hash ของโค้ดกราฟิกตอนที่แต่ง ใช้บอกว่าภาพเปลี่ยนแล้ว |
| `pointId` | จุดเน้นที่เสียงนี้ทำให้ (ถ้ามี) |
| `from` | ระดับต่ำสุดที่เล่น: `light` · `medium` · `heavy` |
| `role` | หน้าที่ ภาษาไทยหนึ่งประโยค ไม่เกิน 200 ตัวอักษร |
| `loudness` | `soft` · `normal` · `strong` |
| `seconds` | ความยาวรวมหางเสียง 0.2–6 วินาที |
| `words` | คำที่พูดช่วงนั้นพร้อมวินาทีนับจากเริ่มเสียง ณ ตอนที่แต่ง (แบบ `MotionWord`) |
| `code` | ฟังก์ชันที่ Claude เขียน · `null` เมื่อยังไม่ได้แต่งหรือแต่งไม่สำเร็จ · จำกัด 20,000 ตัวอักษร |
| `failed` · `instruction` · `editFailed` · `previous` | แบบกราฟิก 0.5.1 (`previous` เก็บ `code` `seconds` `words` `version` `graphicHtml` `instruction`) |
| `version` | รุ่นของกติกา (`SOUND_VERSION`) |
| `off` | ผู้ใช้ปิดไว้ |

ไม่มี `edited`: การแก้ไม่ทำให้เสียงเป็นของผู้ใช้ (แบบกราฟิก 0.5.1) "คิดใหม่: เสียง" แทนเสียงที่แต่งทั้งหมด

**เสียงเก่า (`flair.cues`):** ไม่ล้างตอนอัปเดต · เสียง CapCut ของ AI (`edited:false`) ยังเขียนลงดราฟต์จนกว่าจะ "คิดใหม่: เสียง" หรือรอบวางแผนใหม่ ซึ่งลบทิ้ง · เสียงที่ผู้ใช้เลือกเอง (`edited:true`) อยู่ต่อ ขึ้นในรายการ "เสียงที่คุณเลือกเอง" ลบได้ · ไม่มีการเพิ่มหรือเปลี่ยนเสียง CapCut อีก (`setSoundCue` เหลือแค่ลบ)

## 5. กติกาที่ให้ Claude (contract)

ภาษาอังกฤษแบบกติกากราฟิก ตั้งต้นจาก `docs/plans/2026-10-01-sound-spike/contract.txt`:

- ตอบฟังก์ชันเดียว `function compose(ctx, cue, kit) { ... }` ไม่มี code fence ไม่มีคำอธิบาย
- `ctx` = `OfflineAudioContext` 2 ช่อง 48 kHz ยาว `cue.length` วินาที · ต่อทุกอย่างเข้า `ctx.destination` · ตั้งเวลาเป็นวินาทีนับจาก 0 · ไม่เรียก `startRendering`
- `cue` = `{ length, words }` (ความยาวรวมหางเสียง และคำพร้อมเวลา) · `kit` = `rand()` (seeded, `Math.random` ก็ตัวเดียวกัน) · `noise(seconds)` · `reverb(seconds, decay)` · `note(name)`
- ใช้ Web Audio node และ automation ได้ทุกแบบ · ไม่มีเน็ต ไฟล์ ตัวจับเวลา promise
- เปิดและปิดทุกเสียงแบบไม่มีคลิก · peak ไม่เกินราว 0.8
- หลบเสียงพูด: ระหว่างคำ ช่วง 300–3000 Hz เบาหรือเสียงสั้นแบบเคาะ · บานในช่องว่าง
- เป็นเสียงเอฟเฟกต์ ไม่ใช่เพลง · ทำให้เสียงมีชั้นและดูออกแบบมา
- ตามชุดเสียงของคลิป · ลงจังหวะตรงเวลาที่มันเป็นของ (คำ หรือสิ่งที่เกิดในภาพของกราฟิก)

## 6. การตรวจ

### 6.1 ตรวจโค้ด (ก่อนเรนเดอร์ทุกครั้ง)

ตัวตรวจใหม่ `sound/lint.ts` (หยิบกฎจาก `motion/lint.ts` ที่ใช้ได้):

- รูปร่าง: ข้อความทั้งหมดเป็น `function compose(ctx, cue, kit) { … }` เดียว ไม่มีอะไรนอกฟังก์ชัน · ไม่ว่าง · ไม่เกิน 20,000 ตัวอักษร
- ห้าม: เน็ต (fetch, XMLHttpRequest, WebSocket, EventSource, sendBeacon, RTC*) · thread และช่องทาง (Worker, postMessage, BroadcastChannel, MessageChannel) · โหลดหรือสร้างโค้ด (import, eval, Function) · หน้าเพจและเบราว์เซอร์ (document, window, self, globalThis, location, navigator, history, storage, indexedDB, open) · เวลา (setTimeout, setInterval, requestAnimationFrame, Date, performance) · `\u` `\x` escape · `AudioContext` (ใช้ `ctx` ที่ให้เท่านั้น) · `decodeAudioData` `MediaElement` `MediaStream` `AudioWorklet`

### 6.2 ตรวจเสียง (หลังเรนเดอร์)

- เรนเดอร์จบภายใน 20 วินาที ไม่มี error
- ไม่เงียบ: peak อย่างน้อย 0.01
- ไม่แตก: peak เกิน 1.0 ได้ก่อนปรับ แต่ถ้าเกิน 4.0 ถือว่าผิด (มักเป็น gain ที่หลุด)
- ไม่มีคลิก: 5 มิลลิวินาทีแรกและสุดท้ายเบากว่า 0.05
- ตัดความเงียบท้ายที่เกิน 0.1 วินาทีออก ความยาวจริงเก็บเป็นความยาวของไฟล์

### 6.3 ซ่อม

แบบกราฟิก: `repairBrief` (โจทย์เดิม ปัญหา โค้ด) หนึ่งรอบ · ล้มอีกเก็บปัญหา 3 ข้อแรก

## 7. เรนเดอร์

- **ที่เรนเดอร์:** หน้าต่างซ่อนของแอปเอง (Chromium ใน Electron) ไม่ต้องติดตั้งชุดเรนเดอร์กราฟิก เพราะกราฟิกปิดเป็นค่าเริ่มต้นแต่เสียงเปิด
- **ล้อมไว้:** session แยก (`partition` ของตัวเอง ไม่แชร์ `boxblack-media://` กับหน้าหลัก) · ทุกคำขอเครือข่ายถูกยกเลิก (`webRequest`) · ปฏิเสธทุก permission · ไม่มี preload (เข้า IPC ไม่ได้) · `sandbox` · ห้ามเปิดหน้าต่างใหม่และห้ามเปลี่ยนหน้า · หน้าต่างไม่รับ `app:event` และไม่นับเป็นหน้าต่างของแอป (ปิดแอปตามปกติ เปิดหน้าต่างหลักใหม่ได้ตามปกติ) · สร้างเมื่อต้องเรนเดอร์ ปิดเมื่อว่าง
- **วิธีรัน:** ส่ง harness (แบบ `harness.js` ของการทดลอง) กับโค้ดเข้า `executeJavaScript` · ได้ WAV กลับมาเป็นข้อมูล · ทีละเสียง (คิวเดียว) หมดเวลา 20 วินาที
- **ไฟล์:** `~/Movies/CapCut/BOXBLACK/sounds/<hash>.wav` (CapCut เข้าถึงได้แค่ใต้ `~/Movies`) · hash จากโค้ด ความยาว เวลาของคำ ความดัง และ `SOUND_VERSION` · ทำครั้งเดียว ใช้ซ้ำ · ทำความสะอาดไฟล์ที่ไม่มีดราฟต์ไหนใช้แบบไฟล์กราฟิก (`graphics-files.ts`) แต่แยกรูปแบบชื่อและโฟลเดอร์
- **ปรับความดัง:** ffmpeg ที่มากับแอป (`ebur128` วัด แล้ว `volume` ปรับ เขียน `pcm_s16le`) · เพิ่ม `ebur128` เข้า `REQUIRED_FILTERS` ของ `tool-check`

## 8. การวางและเวลา

- เวลาเริ่ม = เวลาของ anchor บนคลิปที่ตัด (`placeOf`) · เสียงที่คำของตัวเองถูกตัดออก และมีจุดเน้น เล่นที่ต้นจุดแทน (`itemPlaceOf`) · ไม่มีจุดเน้นและคำถูกตัด = ไม่ได้วาง (นับใน "วางไม่ได้")
- เสียงที่ผูกกับกราฟิกเริ่มพร้อมกราฟิก (anchor เดียวกัน) และตามกราฟิกเสมอ
- **เก่า (stale)** เมื่อ: คำในช่วงนั้นเปลี่ยน (ข้อความหรือจำนวน) · เล่นได้สั้นกว่าที่แต่งเกิน 0.1 วินาที · `SOUND_VERSION` เปลี่ยน · กราฟิกที่ผูกเปลี่ยนโค้ด (`graphicHtml` ไม่ตรง) · เสียงที่เก่าไม่ถูกเขียนลงดราฟต์ ขึ้นว่า "การตัดช่วงนี้เปลี่ยนไป กดแก้หรือทำใหม่" หรือ "ภาพเปลี่ยน กดทำใหม่"
- ระดับ: เล่นเมื่อระดับที่เลือก ≥ `from` และ (ไม่มี `pointId` หรือจุดนั้นผ่านระดับ) · Claude แต่งทุกเสียงในรายการ ไม่ว่าระดับไหน การเปลี่ยนระดับจึงไม่ต้องเรียก Claude

## 9. เขียนลง CapCut

- ไฟล์ WAV วางบนแทร็กเสียงแบบเสียงเดิม (เลนว่างแรก) · ไม่ตัดที่ 1.5 วินาทีแบบเสียง CapCut · volume 1.0 เพราะปรับความดังในไฟล์แล้ว
- รูปแบบ material และรายการในถังสื่อ (`draft_meta_info`) ของไฟล์เสียงในเครื่องยังไม่รู้ → **งานแรกของแผน:** ใส่ WAV ในโปรเจกต์ทดสอบด้วยมือใน CapCut อ่านว่ามันเขียนอะไร แล้วเขียนแบบเดียวกันด้วยโค้ดลง 0917 (สำรองก่อน) ให้ผู้ใช้เปิดดูและ export
- ชนิดของ material ต้องไม่ใช่ `sound` (ไม่ให้ `sound-library` นับเป็นเสียง CapCut และไม่ให้ `soundNeedsPro` นับว่าต้อง Pro) และไม่โผล่เป็นสื่อแทรก
- เสียงที่ยังไม่ได้แต่ง แต่งไม่สำเร็จ เก่า หรือปิด ไม่ถูกเขียน · ชีตยืนยันก่อนเขียนบอกจำนวน "เสียงที่แต่ง N เสียง" และจำนวนที่เว้นไว้พร้อมเหตุ

## 10. หน้าจอ (แท็บเสียง)

- สวิตช์เสียงเหมือนเดิม · แถบ "จุดเน้นเปลี่ยน คิดใหม่" เหมือนเดิม
- **รายการเสียงที่แต่ง** เรียงตามเวลา แถวละเสียง: เวลา · หน้าที่ (สองบรรทัด ที่เหลือใน title) · "แก้ล่าสุด: …" (ถ้ามี) · ผูกกับ (จุดเน้น หรือกราฟิก) · ระดับที่เริ่มเล่น · สถานะ (กำลังแต่ง… · กำลังแก้… · ยังไม่ได้แต่ง · พร้อม · แต่งไม่สำเร็จ · เหตุ · การตัดช่วงนี้เปลี่ยนไป · ภาพเปลี่ยน · ปิดอยู่) · บรรทัด "แก้ไม่สำเร็จ · …" (ถ้ามี) · ความยาว
- ปุ่ม: ทำใหม่ · แก้ (เสียงที่แต่งแล้ว ช่องพิมพ์ใต้แถวแบบกราฟิก 0.5.1 ไม่เกิน 300 ตัวอักษร) · ย้อน (มีชิ้นก่อนหน้า) · ปิด/เปิด · ลบ
- **รายการ "เสียงที่คุณเลือกเอง"** (มีเมื่อมีเสียง CapCut ที่ผู้ใช้เคยเลือก) แถวละเสียง: เวลา · ชื่อเสียง · ปุ่มลบ
- ไม่มีปุ่มฟัง (ผู้ใช้เลือก)
- ข้อความทั้งหมดอยู่ใน `i18n.ts`

## 11. ความสัมพันธ์กับของอื่น

- **แก้หรือทำกราฟิกใหม่:** ในรอบเดียวกัน หลังกราฟิกเก็บแล้ว แต่งเสียงที่ผูกกับกราฟิกนั้นใหม่ด้วยโค้ดกราฟิกใหม่ (แบบทำใหม่ของเสียง แต่ใช้ชุดเสียงเดิมของคลิป) · แถบแผนบอก "กำลังแต่งเสียง 0 จาก 1" ต่อจากกราฟิก · กราฟิกล้ม = ไม่แตะเสียง
- **ย้อนกราฟิก:** เสียงที่ผูกย้อนตามด้วย ถ้า `previous` ของเสียงตรงกับโค้ดกราฟิกที่กลับมา ไม่ตรงก็ขึ้น "ภาพเปลี่ยน กดทำใหม่"
- **ปิดหรือลบกราฟิก:** เสียงที่ผูกเงียบหรือหายตาม (ลบกราฟิก = ลบเสียงที่ผูก)
- **คิดใหม่: กราฟิกและเทคนิค:** กราฟิกที่หายพาเสียงที่ผูกไปด้วย · แท็บเสียงขึ้นแถบคิดใหม่เหมือนเดิม
- **ลบจุดเน้น:** เสียงที่ผูกจุดนั้นหาย (เสียงที่แต่งไม่มีของผู้ใช้)
- **ข้อความเด่นเปลี่ยน ซูมเปลี่ยน:** ไม่แต่งเสียงใหม่เอง · ผู้ใช้คิดใหม่เสียงเองเมื่อต้องการ

## 12. การทำงานที่ผู้ใช้สั่ง (เหมือนกราฟิก)

- `redoSound` · `editSound` (โจทย์แก้แบบ `editBrief`) · `undoSound` · `setSound(anchor, { off } | null)` · เป็นงาน "เสียง" รอบเดียว ห้ามซ้อนกับรอบอื่น (ยกเว้น undo ที่ไม่ใช่รอบ แต่ห้ามระหว่างมีรอบ)
- แต่งใหม่ทุกครั้งเขียนสำหรับที่ว่างจริงตอนนี้ (ความยาว คำ และโค้ดกราฟิกตอนนี้) เสียงเก่าจึงหายค้างไปพร้อมกัน

## 13. ทดสอบ

- core: ตัวตรวจโค้ด (ทุกกฎ มีชิ้นผ่านและชิ้นไม่ผ่าน) · โจทย์วางแผนและโจทย์แต่ง · อ่านคำตอบแผน (ทิ้งเสียงที่ไม่มีที่ ที่ซ้ำ หรือผิดรูป)
- main: วางแผน แต่ง ตรวจ ซ่อม เก็บ หยุด · เก่า · ระดับ · ผูกกราฟิก (แก้ ทำใหม่ ย้อน ปิด ลบ) · เขียนลงดราฟต์ (material แทร็ก เลน ถังสื่อ) · ทำความสะอาดไฟล์ · หน้าต่างเรนเดอร์ปฏิเสธเน็ตและ permission (ทดสอบด้วยโค้ดที่ตั้งใจหนี ข้ามตัวตรวจ)
- renderer: รายการเสียง ปุ่ม ช่องแก้ สถานะ รายการเสียงที่เลือกเอง
- controller: mutation · ลองจริงกับ Claude บน 0917 (วางแผนทั้งคลิป แก้ ย้อน ทำกราฟิกใหม่แล้วเสียงตาม หยุด) · เขียนลง 0917 ให้ผู้ใช้เปิดฟังใน CapCut และ export แล้วคืน

## 14. ข้อจำกัดและความเสี่ยงที่รู้

- เสียงสังเคราะห์ ฟีลการ์ตูนหรือเกม ไม่ใช่เครื่องดนตรีจริง · ถ้าต้องการภายหลัง เพิ่มชุดเสียงเครื่องดนตรีฟรี (soundfont) ได้ เป็นงานแยก
- ไม่มีปุ่มฟังในแอป
- รอบวางแผนนานขึ้นราว 1–3 นาทีต่อคลิป และใช้โควตา Claude มากขึ้น (หนึ่งการเรียกต่อเสียง)
- โค้ดของ Claude รันในหน้าต่างซ่อนของแอป (ล้อมตาม §7) แทน Chrome แยกของชุดเรนเดอร์ · ต้องทดสอบการล้อมด้วยโค้ดที่ตั้งใจหนี
- CapCut อาจรับไฟล์เสียงในเครื่องไม่ได้แบบที่คิด · งานแรกของแผนพิสูจน์ก่อนทำส่วนอื่น
- ความดังตั้งต้น (−30 / −26 / −22 LUFS) อาจต้องปรับหลังผู้ใช้ฟังจริง
