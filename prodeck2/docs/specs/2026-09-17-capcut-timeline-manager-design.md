# BOXBLACK — โปรแกรมจัดการ timeline ของ CapCut (design v1)

วันที่: 2026-09-17 · สถานะ: ตกลงขอบเขตแล้ว (ผลจากการ grill 23 ข้อ) · ยังไม่เริ่มเขียนโค้ด

## 1. สินค้าคืออะไร

Desktop app (macOS ก่อน, Windows ทีหลัง) ขายแบบ license รายเดือน/รายปี
ผู้ใช้เลือกโปรเจค CapCut → แอปถอดเสียง + ทำความเข้าใจภาพ → AI วางโครงเรื่อง →
ผู้ใช้ยืนยัน/แก้โครงเรื่อง → แอปเขียน **rough cut** ลง timeline ของโปรเจคนั้น

ขอบเขต v1 = rough cut เท่านั้น: ตัดช่วงเสีย/เงียบ/เทคซ้ำ + เรียงลำดับตามโครงเรื่อง
ลง main video track เส้นเดียว · B-roll ซ้อน track, เพลง, transition = v2 · ซับ: ย้ายมาทำเป็น M8 (ผู้ใช้ขอ 2026-09-17)

## 2. ข้อเท็จจริงที่สำรวจจากเครื่องจริง (CapCut Mac 9.4.0)

- Draft อยู่ที่ `~/Movies/CapCut/User Data/Projects/com.lveditor.draft/<ชื่อ>/`
- รายชื่อโปรเจค: `root_meta_info.json` → `all_draft_store[]` (`draft_name`, `draft_fold_path`, `tm_duration`)
- Timeline: `draft_info.json` เป็น plaintext JSON ไม่เข้ารหัส
  - `tracks[].segments[]` มี `material_id`, `source_timerange`, `target_timerange` หน่วย microsecond
  - `materials.videos[].path` ชี้ไฟล์สื่อจริงบนดิสก์
  - เวอร์ชัน: `platform.app_version`, `new_version`
- Timeline JSON มี **6 สำเนาเหมือนกันทุก byte**: root `draft_info.json`, `draft_info.json.bak`,
  `template-2.tmp` และชุดเดียวกันใน `Timelines/<main_timeline_id>/` (id จาก `Timelines/project.json`)
  → ตัวเขียนต้องอัปเดตทุกสำเนา + `draft_meta_info.json` (`tm_duration`, `tm_draft_modified` ฯลฯ)
- Media bin: `draft_meta_info.json` → `draft_materials[]` (type 0 = ไฟล์ที่ import, มีทั้ง video/photo)
  แยกจาก `materials.videos` ของ timeline (ตัวอย่าง draft `0815`: bin 63 ไฟล์, ใช้บน timeline 25)
- ฟอร์แมตเปลี่ยนระหว่างเวอร์ชัน (9.2.0 → 9.4.0 มี field เพิ่ม)

ยืนยันเพิ่มจาก M0 spike (2026-09-17, CapCut 9.4.0):
- **1 video material ต่อ 1 segment เสมอ** แม้ไฟล์เดียวกัน · ถ้าแชร์ material CapCut จะ save ออกมาเป็น entry ซ้ำหลายตัวที่ **id เดียวกัน**
- แต่ละ video segment ต้องมี extra material 6 ตัวตามลำดับ: speeds, placeholder_infos, canvases, sound_channel_mappings, material_colors, vocal_separations
- `local_material_id` ของ video material = id ของไฟล์ใน media bin
- เวลาคิดเป็นเฟรมแล้วแปลงกลับ: `floor(frame × 1e6 / fps)` ทั้งขอบต้นและขอบท้าย (source 23..78 @30fps = start 766666, duration 1833334)
- CapCut ยอมรับตัวเลขที่ JSON.stringify เขียนเป็นจำนวนเต็ม (`30` แทน `30.0`)
- Home อ่านความยาวจาก `root_meta_info.json` (`tm_duration`) · cover สร้างใหม่เองตอนเปิดโปรเจค
- เปิดโปรเจคแล้ว CapCut save ทับทันที และเพิ่ม `hdr_vivid_settings: null` ให้ segment

ค่าปริยายที่ผมเลือกให้โดยไม่ได้ถาม (แก้ได้):

## 4. สถาปัตยกรรม

```
apps/desktop (Electron)
  main process
    capcut/        reader (root_meta, draft_info, draft_meta) · writer (6 สำเนา + meta) · backup/restore · process gate
    media/         ffmpeg: แตกเสียง, scdet, สุ่มเฟรม, contact sheet, blur/shake/freeze/silence detect
    asr/           adapter: whisper.cpp | scribe   (+ ตัวรวม token ไทยเป็นคำ จาก prodeck1 asr-local.ts)
    llm/           LlmTransport: anthropic API | claude CLI   (จาก prodeck1 llm.ts / llm-cli.ts)
    planner/       โครงเรื่อง (beat list) ← transcript + shot descriptions + brief
    cut/           compiler: beats + word timing + preset → EDL (fillers.ts, retakes.ts จาก prodeck1)
    license/       activate, token refresh, ดึง prompt/config
  renderer (React)  Activate → เลือกโปรเจค → วิเคราะห์ → ยืนยันโครงเรื่อง → เขียน timeline · Settings

apps/server (Next.js)   POST /activate · POST /refresh · GET /config (prompts, presets, capcut whitelist) · /admin
packages/core           types ร่วม (Draft, Transcript, Shot, Beat, EDL, LicenseToken)
```

แผนตัดทั้งหมดอ้างอิงพิกัด **ไฟล์ต้นทาง + เวลาในไฟล์ต้นทาง** ไม่ใช่เวลาบน timeline
→ ตัวเขียนแปลง EDL เป็น segment ตอนท้ายสุด

## 5. ความเสี่ยงที่รับทราบแล้ว

1. **Claude CLI mode ในแอปขายเชิงพาณิชย์** — เอกสาร Agent SDK ของ Anthropic ระบุว่าถ้าไม่ได้รับอนุมัติก่อน
   third-party ห้ามเสนอ claude.ai login/rate limits ในสินค้าของตน และไม่มีข้อยกเว้นสำหรับการ spawn CLI
   ที่ลูกค้า login ไว้ (https://code.claude.com/docs/en/agent-sdk/overview.md) · เจ้าของโปรเจคเลือก**คงโหมดนี้ไว้และรับความเสี่ยง**
   · การบรรเทา: API เป็นค่าเริ่มต้น, CLI เป็น opt-in มีคำเตือน, สลับ transport ได้จุดเดียว
2. **กัน crack ไม่ได้เต็มที่** — AI รันบนเครื่อง/ด้วย key ลูกค้า server จึงไม่มีงานที่ขาดไม่ได้
   ผูกเครื่องกันแชร์ key ได้ แต่ patch ข้ามตัวเช็คฝั่ง client ยังทำได้ · ทางหนีทีหลัง: ย้าย `cut/` compiler ขึ้น server
   (จึงต้องเขียนเป็น pure function ตั้งแต่ต้น)
3. **ฟอร์แมต draft ไม่มีเอกสาร + เปลี่ยนตามเวอร์ชัน** — บรรเทาด้วยข้อ 18 + backup ทุกครั้ง
4. **ส่งรูปเข้า `claude -p`** ไม่มีวิธีที่ document ไว้ — ต้อง spike (เขียน contact sheet ลง temp + อนุญาต `Read` tool อย่างเดียว)
