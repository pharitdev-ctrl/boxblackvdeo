# ติดตั้ง BOXBLACK บน Mac

## สิ่งที่ต้องมี

- Mac ชิป Apple (M1 ขึ้นไป) และ macOS 12 ขึ้นไป
- CapCut สำหรับ Mac (ทดสอบกับเวอร์ชัน 9.4)
- อินเทอร์เน็ต สำหรับ Claude และให้ CapCut โหลดเสียงประกอบกับแอนิเมชันข้อความตอนเปิดโปรเจกต์ครั้งแรก
- ช่องทางใช้ Claude อย่างใดอย่างหนึ่ง: Anthropic API key ของคุณเอง หรือบัญชี Claude แพ็กเกจ Pro, Max, Team หรือ Enterprise (ผ่าน Claude Code ซึ่งติดตั้งจากในแอปได้ ต้องใช้ macOS 13 ขึ้นไป)
- ช่องทางถอดเสียงอย่างใดอย่างหนึ่ง: ถอดบนเครื่อง (ฟรี) หรือ ElevenLabs API key ของคุณเอง

ไม่ต้องติดตั้งโปรแกรมอื่นเพิ่ม: ffmpeg และ whisper-cli ที่ BOXBLACK ใช้ **มากับแอปแล้ว** ทุกอย่างที่เหลือตั้งได้จากในแอป

## 1. ติดตั้งแอป

1. เปิดไฟล์ `boxblack-<เวอร์ชัน>-arm64.dmg`
2. ลากไอคอน BOXBLACK ไปวางในโฟลเดอร์ Applications
3. เปิด BOXBLACK จากโฟลเดอร์ Applications

### เปิดครั้งแรก

BOXBLACK ยังไม่ได้ลงทะเบียนผู้พัฒนากับ Apple ครั้งแรก macOS จึงไม่ยอมให้เปิด ให้ทำตามนี้ครั้งเดียว

1. เมื่อขึ้นข้อความว่าเปิด BOXBLACK ไม่ได้ ให้กด **Done**
2. ไปที่ **System Settings → Privacy & Security**
3. เลื่อนลงไปที่ส่วน Security จะเห็นข้อความว่า BOXBLACK ถูกบล็อก กด **Open Anyway**
4. ใส่รหัสผ่านของเครื่อง แล้วกด **Open**

ครั้งต่อไปเปิดได้ตามปกติ

## 2. ตั้งค่า

กด **ตั้งค่า** ที่แถบด้านบนขวา แท็บที่ยังต้องตั้งมีจุดสีส้ม และหน้าตั้งค่าจะเปิดที่แท็บนั้นให้เอง

- **ทั่วไป → เครื่องมือบนเครื่องนี้:** ffmpeg และ whisper-cli ขึ้นว่ามากับแอป
- **ถอดเสียง:**
  - **บนเครื่อง:** กดดาวน์โหลดโมเดล (ประมาณ 1.1 GB ครั้งเดียว) · ครั้งแรกที่ถอดเสียงจะช้ากว่าปกติไม่กี่วินาที เพราะ macOS เตรียมการ์ดจอให้
  - **ElevenLabs Scribe:** ใส่ API key ของคุณ
- **Claude:**
  - **Anthropic API:** ใส่ API key ของคุณ
  - **Claude Code บนเครื่องนี้:** กด **ติดตั้ง Claude Code** (โหลดจาก Anthropic ประมาณ 200 MB ไม่ต้องใช้รหัสผ่านเครื่อง) แล้วกด **ล็อกอินด้วยบัญชี Claude** เบราว์เซอร์จะเปิดหน้าของ Claude ให้กดอนุญาต แล้วกลับมาที่แอป ถ้าหน้าเว็บให้รหัสมาแทน ให้วางในช่องที่แอปแสดง · ถ้ามี Claude Code ที่ล็อกอินไว้แล้ว แอปใช้ตัวนั้นเลย

ครั้งแรกที่บันทึก API key macOS อาจถามว่า BOXBLACK ขอใช้ข้อมูลใน Keychain ให้กด **Always Allow** ส่วนครั้งแรกที่อ่านวิดีโอในโฟลเดอร์ Downloads, Desktop หรือ Documents ให้กด **Allow**

## 3. ใช้งาน

1. **ปิด CapCut ก่อนเริ่ม** BOXBLACK จะไม่ทำงานระหว่างที่ CapCut เปิดอยู่
2. เลือกโปรเจค → วิเคราะห์ → ให้ AI วางโครงเรื่อง → ยืนยัน → เขียนลง CapCut
3. BOXBLACK สำรองโปรเจคไว้ทุกครั้งก่อนเขียน ถ้าผลไม่ถูกใจ ให้เปิดโปรเจคนั้นแล้วกู้คืนจากปุ่ม **สำรอง** บนแถบด้านบน

## อัปเดตเป็นเวอร์ชันใหม่

ดาวน์โหลด DMG ใหม่ แล้วลาก BOXBLACK ไปวางทับของเดิมในโฟลเดอร์ Applications การตั้งค่าและผลวิเคราะห์ยังอยู่ครบ

## ถ้ามีปัญหา
- **"Claude Code ยังไม่ได้ล็อกอิน หรือล็อกอินหมดอายุ":** ไปที่ **ตั้งค่า → Claude** แล้วกด **ล็อกอินด้วยบัญชี Claude**
